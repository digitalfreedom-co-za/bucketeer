# Code of Conduct

Bucketeer is a small open project run by a single publisher
(DigitalFreedom / Berger & Rosenstock GbR). We ask everyone who
interacts with the repository — through issues, pull requests,
discussions, or any other channel — to follow a few simple rules.

## In short

- **Be kind.** Disagreement is fine; personal attacks are not.
- **Stay on topic.** Bucketeer is a macOS object-storage browser.
  Threads that drift into unrelated debates get closed.
- **Assume good faith.** If a comment lands wrong, ask before
  escalating.
- **No politics, religion, sexual content, or harassment.** This
  repository is a workplace for everyone who participates.

## Concretely

The following are not acceptable in any space connected to this
project (issues, PRs, commits, discussions, social posts that
@-mention the project):

- Personal attacks, insults, slurs, or disparaging remarks
  targeting any individual or group
- Sexual or sexually-suggestive content
- Doxing or sharing private information without consent
- Sustained disruption — repeatedly derailing threads, ignoring
  maintainer requests to refocus, brigading
- Spam, low-effort drive-by criticism without engagement, or
  obvious AI-generated boilerplate that wastes maintainer time

## Enforcement

The publisher (currently Marcel R. G. Berger, hello@digitalfreedom.co.za)
moderates this project. Enforcement actions are proportional:

1. **Private nudge** — a maintainer asks you to adjust the tone
   or refocus the thread.
2. **Public correction** — a maintainer comments publicly that
   a contribution is off-topic / against the rules and asks you
   to revise.
3. **Temporary ban** — for sustained or severe violations, the
   account is blocked from interacting with the repository for
   30 days.
4. **Permanent ban** — for repeat offences or any harassment
   directed at maintainers or contributors.

To report a violation, email hello@digitalfreedom.co.za. Reports
stay confidential.

## Coverage

This Code of Conduct applies to:

- The Bucketeer GitHub repository (issues, PRs, discussions, wiki)
- Public channels where the project is officially represented
  (e.g. App Store responses, support tickets)

It does not apply to private interactions outside those spaces;
we don't moderate behaviour on third-party platforms unless it
spills back into the project.
